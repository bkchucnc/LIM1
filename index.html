Mã Nguồn Google Apps Script (Code.gs) — Đồng Bộ 6 Sheet & Tự Động Kéo Định Kỳ Từ Firebase

Tích hợp sẵn hàm syncFromFirebaseToSheets() và setupPeriodicSyncTrigger() để Google Sheets tự động lấy dữ liệu định kỳ từ Firebase mỗi giờ!

BƯỚC 1: TẠO FIREBASE REALTIME DATABASE

  1. Truy cập console.firebase.google.com → Tạo dự án mới → Chọn Build → Realtime Database → Create Database.
  2. Trong tab Rules, dán cấu hình cho phép đọc/ghi nhánh lims_nafiqpm1 rồi bấm Publish.
  3. Sao chép Database URL (ví dụ: https://ten-du-an-default-rtdb.asia-southeast1.firebasedatabase.app) dán vào Tab 1 và nhấn "Đẩy Dữ Liệu Lên Firebase Ngay".

BƯỚC 2: KẾT NỐI GOOGLE SHEETS & BẬT ĐỒNG BỘ ĐỊNH KỲ TỰ ĐỘNG

  1. Mở file Google Sheet → Chọn Tiện ích mở rộng (Extensions) → Apps Script.
  2. Sao chép mã ở Tab 2 dán vào Code.gs → Lưu lại.
  3. Chọn hàm setupPeriodicSyncTrigger trên thanh công cụ Apps Script và nhấn Chạy (Run) để Google Sheets tự động kéo dữ liệu từ Firebase mỗi giờ.
  4. Nhấn Triển khai (Deploy) → Tùy chọn triển khai mới → Ứng dụng web (Web app) → Quyền truy cập: Bất kỳ ai (Anyone) → Dán Web App URL vào Tab 1.
Hỗ trợ hoạt động độc lập hoặc đồng bộ kết hợp Firebase + Google Sheets.
